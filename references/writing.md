# 文字与结构

| 文体 | 组织方式 | 避免 |
|---|---|---|
| 企业资讯 | 事实与变化 → 对读者的影响 → 行动信息 | 空泛自我表扬 |
| 产品发布 | 使用场景 → 功能与证据 → 使用步骤 → 获取方式 | 杜撰效果、用户证言或参数 |
| 活动回顾 | 关键结果 → 有意义的现场 → 参与者与贡献 → 后续 | 流水账和虚构掌声 |
| 知识科普 | 问题 → 解释 → 例子 → 操作或判断方法 | 只用术语，不解释因果 |
| 人物访谈 | 背景 → 问答或经历 → 具体选择 → 观点归属 | 将润色写成逐字引语 |
| 品牌故事 | 具体行动 → 变化与困难 → 价值如何体现 | 用使命口号替代事实 |
| 公益纪实 | 需求 → 行动 → 可核实成果 → 参与方式 | 消费隐私或捏造受助者故事 |
| 服务指南 | 适用对象 → 步骤 → 条件与例外 → 联系入口 | 把重要限制藏进折叠 |

段落只推进一个主要意思，长短句结合；加粗用于少量核心判断。简繁体、数字、单位、链接及人名按稿件统一。转折和提问必须推动逻辑，不能作为每段固定开头。

指定作者风格时，从用户给定样例提炼事实组织、语气、节奏和论述方法。不要把风格名当作署名，不添加该人物没有说过的发言。英文版本保持信息和立场，以自然英文组织句法。
