# 样式与组件

| ID | 方向 | 首屏与正文结构 |
|---|---|---|
| corporate | 商务简报 | 紧凑左对齐、细分隔线、段落清楚 |
| editorial | 人文特刊 | 衬线大标题、宽图、长文阅读节奏 |
| launch | 产品发布 | 深色首屏、醒目重点、浅色正文卡 |
| technology | 科技长卷 | 浅蓝紫、几何底纹、章节图形 |
| education | 知识课堂 | 暖纸色、编号章节、步骤式信息 |
| lifestyle | 生活方式 | 柔和暖色、开放留白、照片优先 |
| interview | 人物访谈 | 留白首屏、引用式章节、人物图 |
| event | 活动庆典 | 活泼紫色、时间节点、错落照片 |
| report | 数据观察 | 紧凑蓝灰、条目结构、证据说明 |
| nonprofit | 公益纪实 | 绿色、克制温暖、行动过程 |
| minimal | 极简公告 | 黑白、少装饰、核心信息直接 |
| luxury | 品牌画册 | 深棕金、居中首屏、较宽留白 |

v0.2 的十二种构图由 `scripts/layouts.py` 独立组织，不再共用“标题—封面—导语—重复卡片”的单一路径。

| ID | 结构上的实质区别 |
|---|---|
| corporate | 摘要在封面前，章节编号与标题并列 |
| editorial | 满幅图片在标题前，章节图片先于正文，辅助图在正文后 |
| launch | 深色标题舞台、产品画面嵌入舞台、章节先展示图片再说明 |
| technology | 几何标题区、独立导语卡、章节标题在白色正文卡外 |
| education | 书页式封面、导读框、圆形步骤序号及正文笔记框 |
| lifestyle | 居中标题与拱形图窗、图文穿插、大留白和辅助双图 |
| interview | 封面图文并置，正文以边栏索引与回答区组织 |
| event | 票券式封面和信息条、章节日期式编号、先照片后叙述 |
| report | 摘要、由真实章节生成的阅读索引、证据图面板 |
| nonprofit | 横幅图片和接续标题、连续纵向行动节点、现场图先行 |
| minimal | 正文先行，封面作为末尾补充图，紧凑文字层级 |
| luxury | 居中大留白刊头、满幅画面、展签式章节和照片后说明 |

颜色可以被品牌覆盖，但应保留对比度。与客户风格不符时可另设计，不必局限于内置十二款。黑白构图对比与“查看实际导出版式”用于判断结构是否真实不同。图片默认保留完整画面；需要裁切时先确认人脸、文字和 Logo 不受影响。

组件：封面、导语、编号章节、引用、步骤、重点说明、多图组合、图注、链接、品牌页尾。优先保留文字，不用图片承载长正文。人物与产品图片不为凑比例裁掉关键部位；多人合影优先完整展示。

动效用于少量装饰与图片，正文不晃动；提供关闭及减少动态效果支持。折叠默认展开，报名条件、重要时间和费用不放在默认隐藏部分。静态导出必须可读、完整。
