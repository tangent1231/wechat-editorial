# 动效与素材实施

动效要有实际可播放的实现，不只用文字写“这里可以动”。第一屏选一个主动作，背景低对比缓慢流动；章节线条用于引导阅读。关键内容、二维码、Logo、真实人物与数据图不晃动、不遮挡。正文不逐字飞入。

## 当前提供的能力

- 工作台：首图与小素材浮动、渐变背景流动、章节线条流光；分组开关、一键暂停，遵循 `prefers-reduced-motion`。
- 首图只在文章配置 `coverMotionSafe: true` 时动。只有确认是可装饰插画后才开启；真实照片、文字海报与身份信息默认保持静止。
- 所有十二款支持章节收起/展开。复制及下载始终来自完整原文，不从收起后的页面抓取。
- `assets/motion/`：两款 6 秒循环 GIF 与对应 PNG 静态版本；原始绘制脚本 `scripts/make_motion_assets.py`（仅重新制作 GIF 时需 Pillow，正文构建不需要）。素材浏览页默认静态，可主动播放。

## 交付分层

工作台默认打开公众号复制版；取消“公众号复制预览”勾选即可查看下述动态设计。

1. 本地设计预览：可展示图片组合、慢动背景、流光和折叠。不能据此声称微信兼容。
2. 完整富文本：内联样式、完整纵向图片、可编辑文字。浏览器 CSS 动画不参与导出，不能将静态导出标记为“带动态背景”。
3. 可上传动图：独立 GIF 与 PNG 备用图，按主题与底色选择，上传到秀米或微信后核对是否保留播放、比例及大小。当前随包 GIF 未经平台导入验收。
4. 正式折叠或横向滑图：使用目标编辑器支持的组件重建并手机预览；缺少目标环境时明确待验证，不用浏览器 JS 冒充公众号互动。

## 验证与持续维护

浏览器检查至少包含：跨时间的实际画面变化、一键暂停冻结、单项关闭、系统减少动态效果、375/430px、全部收起后完整复制。通用化、重构或新增主题后，重跑动效验收，不能只检查静态截图。素材库应接入示例而不只是存放文件；每组按需配主视觉、章节装饰和图注，避免所有主题重复同一张几何占位图。
