# Agent 工作流程

## 从材料到成品

1. 整理：提取正文、附件图片、品牌文件、来源与限制；保留原稿副本。列出会影响发布的事实缺口。
2. 编辑：选文体，组织主线；已定稿仅处理排版。引用原话和自己的转述分开。由品牌资料决定语气，不把上一家公司口吻带入。
3. 视觉：按文章内容提出三款有实际图文的方案，推荐一款并说明适用原因。每款说明封面、正文、图片组合及结束页的分工。
4. 素材：逐段检查图片需求。已有图先筛选和核对图注；确需插画时调用环境可用的图像生成工具。生成提示词、用途、输出路径和实际工具渠道一起保存。没有工具就交付可用已有素材与明确缺口，不伪称已生成。
5. 构建：输出 HTML、预览、Markdown、独立素材和品牌配置。不要只交一张不可编辑长图。
6. 验收：对照原文确认段落、数字和引用未遗漏；操作实际复制流程，再查看窄屏。修复后复查受影响的功能。

## 有授权时的并行分工

编辑 Agent 负责事实、结构与文字；视觉 Agent 负责版式、图形语言与图注配对；素材 Agent 负责文件、生成与来源；验收 Agent 从实际交付物检查可读性和完整性。主 Agent 合并时保留单一权威正文，避免不同方案各自改稿。并行不是每次任务的必要条件。

小改稿不启动整套流程。对可逆的版式选择主动试做；对无从确认的引语、客户身份、授权素材或发布去向，先澄清。将建议落实成可查看的样稿后再让用户选择。
