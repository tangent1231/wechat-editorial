# 富文本复制与验证

## 复制内容与预览必须一致

公众号复制版由 `scripts/export_html.py` 生成。工作台的“公众号复制预览”、复制按钮、手动选择排版和 HTML 下载必须使用同一份 `exportHtml`。不能让用户看着依赖 CSS 的设计预览，却复制另一份未说明差异的简化 HTML。

背景色、文字颜色、字号、行高和字体直接内联。字体使用中文系统字体回退链；正文保留为可编辑文字，不为保留字体把整篇转成图片。根容器与顶层区块保留背景色，避免依赖网页 body 或 CSS 伪元素。动态设计仍可切换查看，但普通粘贴不携带 CSS 动画、折叠行为和多列拼图。

## 复制流程

`assets/clipboard.js` 首先在用户点击时走原生复制事件，写入 `text/html` 和带段落换行的 `text/plain`。原生复制失败时才尝试 Clipboard API。两者均失败时引导“手动选择排版”并按 ⌘C / Ctrl+C，不能报告复制成功。

用户在公众号正文使用普通粘贴 ⌘V / Ctrl+V；纯文本粘贴会主动去掉格式。复制会切回公众号复制预览，明确显示实际传输版本。下载文件名为 `<主题>-wechat.html`；直接构建的同名主题 HTML 内容与之相同。

`paste-check.html` 是本地空白可编辑区域，不补入文章样式。粘贴后显示收到的 HTML、内联样式节点、背景声明、图片和正文字符数。检查应真实操作复制和粘贴，不能用设置 innerHTML 代替剪贴板往返。

## 已知边界与证据

2026-11-09，本机内置浏览器 → 系统剪贴板 → Chrome 本地检查页，科技长卷示例已实际粘贴：收到 HTML、88 个内联样式节点、6 张图片；背景色保留为 `rgb(238, 244, 255)`，标题 32px，字体回退链包含 PingFang SC、Microsoft YaHei、Arial、sans-serif。该结果仅覆盖此样例与此环境，不等于所有编辑器兼容性证明。

同次公众号后台实测被工具访问限制中止，未完成后台保存、重新打开或手机预览验证。不要写成“微信端已验证”。

嵌入图片可能被目标编辑器过滤或需要转存。复制成功、图片当场显示、草稿保存后仍保留是不同状态；正式交付需逐项核对。若目标页面无法操作，提供独立 media 素材和本地检查结果，说明待验证项，不绕过访问限制。
