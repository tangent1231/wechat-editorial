# 通用推文工作室 · wechat-editorial

独立的通用微信公众号写作与排版 skill，v0.4.0。支持不同品牌，原 UCup WeChat 保留独立维护。

十二种构图包括：图片开篇、发布舞台、书页笔记、人物并置、票券封面、摘要索引、行动时间轴、文字公告等。可用黑白模式比较结构，也可直接查看实际导出效果。正文内容保持相同，封面次序与图文穿插会保留到导出。

包含十二种版式、3 组 AI 概念主视觉（原图、轻量 JPG、生成提示词）、24 款原创线性 SVG/PNG、4 款 AI 立体图标、2 款独立 GIF 分隔线及静态备用图、按需生成素材的八类风格配方，以及品牌配置、正文构建和交付验收流程。八类生成配方不等于已经生成八套插画。

从 [SKILL.md](SKILL.md) 使用，或运行：

```sh
python3 scripts/build.py examples/article.json --brand examples/brand.json --output output
python3 -m http.server 8898 --directory output --bind 127.0.0.1
```

打开 `http://127.0.0.1:8898/preview.html` 比较方案。默认是公众号复制预览；点击“复制到公众号（保留格式）”，在目标正文普通粘贴。可用 `paste-check.html` 检查实际收到的格式。复制正文后需要在秀米及微信核对图片和实际样式。二维码、作者和审核信息由每家公司自行配置，不存在 UCup 默认值。

Agent 应主动整理资料、制作真实样稿、补充需要的素材、操作导出并检查窄屏。用户要求多款时默认完成三款可比较方案；工具支持且任务明确授权并行时可按编辑、视觉、素材、验收分工。

图片来源及生成记录随素材保存。客户照片、产品资料、Logo 与身份不可由装饰性生成图替代。本工具不会自动公开发布或发送客户材料。

新增：首图与小素材浮动、动态背景、章节流光，可单项关闭或全部暂停；遵循系统减少动态效果。打开 `assets/gallery.html` 浏览素材。浏览器动效为预览，静态富文本不携带 CSS 动画；GIF 可独立上传但需目标平台验证。详见 [动效规范](references/motion.md)。

## v0.4.0 富文本复制修复

- 预览、复制、手动选择与下载共用公众号版 HTML。背景、中文字体、字号和行高内联。
- 原生富文本复制优先，保留 Clipboard API 备用与手动复制入口；复制失败不报告成功。
- 本地真实跨浏览器粘贴已验证背景、字体与 6 张图片；公众号后台验证因工具访问限制未完成。
- 动态设计方案仍保留，普通粘贴输出完整静态文章。
